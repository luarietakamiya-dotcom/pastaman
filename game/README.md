# パスタマン ブレイカー

`game/` に置いたブラウザゲーム。公式HPの「GIOCO」から遊べる。

- `index.html` … ゲーム本体
- `atlas.webp` … キャラ・ブロック・アイテム・エフェクトの画像をまとめたもの
- `voice.mp3` … 必殺技「パスタトーレ！」の声
- `bgm-8bit.mp3` … 通常ステージのBGM（Supereroe 8-bit）
- `bgm-jazz.mp3` … ボーナスステージのBGM（Smoke and Velvet をサビの1:33から切り出したもの）
- `bgm-special.mp3` … 必殺技を満タンで撃ったときの曲（メインテーマのサビ1:43〜を切り出したもの）。終わると元のBGMに戻る
- `config.js` … みんなのランキングの接続先URL

## みんなのランキングを有効にする（Google スプレッドシート）

`config.js` のURLが空のあいだは、ランキングは各自のブラウザの中だけに保存される。
全員で競えるようにするには、一度だけ次の設定をする。

1. Google スプレッドシートを新規作成する（名前は「パスタマン ランキング」など自由）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初からあるコードを全部消して、`gas/ranking.gs` の中身を貼り付けて保存する
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類は「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 「デプロイ」を押して、Google アカウントのアクセス許可を承認する
6. 表示された「ウェブアプリ URL」（`https://script.google.com/macros/s/…/exec`）をコピーする
7. `game/config.js` の `''` の中にそのURLを貼って保存し、GitHub に反映する

スプレッドシートの `log` シートに、登録ごとに1行ずつ記録がたまっていく。
今日・週間（月曜はじまり）・月間・年間・総合のランキングは、この記録から日本時間で自動集計される。
荒らしの記録はその行を消せばランキングから消える。

### 注意

- ランキングはブラウザごとに1人として数える。別の端末で遊ぶと別の人として載る
- スコアはブラウザから送っているので、技術的にはごまかしができる。お遊びのランキングとして使う
- `ranking.gs` を書き換えたら「デプロイを管理」→ 編集 →「新バージョン」で更新する（URLは変わらない）

## ステージ構成

- 通常ステージ24種類。24面ごとに1周で、周回ごとに難しくなる。2周目からは攻撃ブロックが出る
- 10面クリアごとにボーナスステージ（制限時間45秒、ボールを落としても残機が減らない）
- 5周（120面）を終えると、ブロックが無限に湧くラストステージ。ゲームオーバーまで続く
- ムール貝は1発で爆発する
- ボールが鉄の壁のあいだで跳ね続けないための対策：ブロックが3秒壊れないと、跳ね返りの角度を寝かせて横へ進みやすくする。さらに、3秒以内に鉄の壁で6回跳ね返って何も壊していないボールは、0.5秒だけ鉄の壁をすり抜ける（水色の輪が付く）
- ブロックが8秒間ひとつも壊れないと「タップでもう1発！」が出て、タップでお皿からボールを3個追加で撃てる（ボールが同じ場所で跳ね続けて終わらないときの対策）
- ステージクリア後に「次へ」か「中断する」を選べる（6秒で自動的に次へ）。中断するとタイトルに「つづきから」が出る。続きはブラウザに1つだけ保存され、再開すると消える

## リザルトとXへのポスト

ゲームオーバー後に、スコア・到達ステージ・最大コンボ・モード・壊したブロック数・同時ボール最大数・必殺技（満タン）回数・取ったアイテム数・ボーナス回数・ご褒美完食の枚数・プレイ時間・取ったパワーアップ（Lv付き）を表示する。
名前を登録してランキング入りすると（今日・総合で50位以内）、順位がリザルトと画像、ポストの文章に入る。
同じ内容のリザルト画像（1200×675）を自動で作り、次のボタンで共有できる。

- 画像つきでシェア：スマホでは共有メニューが開き、Xを選ぶと画像と文章つきの投稿画面になる。パソコンでは画像を保存してからXの投稿画面を開く（保存した画像を添付してポスト）
- 文字だけでポスト：Xの投稿画面を開く（#パスタマン #パスタマンブレイカー とゲームのURL入り）
- 画像を保存：リザルト画像をダウンロード

## ご褒美パワーアップ

ボーナスステージが終わると（全部消しても時間切れでも）、ランダムな3つから1つパワーアップを選べる。重ねがけでき、「最初から」で始めるとリセットされる（中断→つづきからは引き継ぐ）。取ったものは画面下の床に並んで表示される。

お皿ワイド（+12%／段階）・発射数アップ（+1個）・ゲージ効率（+30%）・アイテム増量（+3個）・効果延長（+35%）・残機+1・しびれ耐性（-40%）・スコアアップ（+25%）・ガードスタート（6秒）・分身スタート（8秒）・貫通スタート（2.5秒）

3択のあとにボーナススキルのルーレットが回り、ランダムなスキルが Lv+1〜3 で追加される（Lv1 60%・Lv2 30%・Lv3 10%）。
レアスキル（発射数アップ・貫通スタート・分身スタート・残機+1）は出にくい。レアスキルか Lv3 が出ると「激熱!!」演出（太鼓がだんだん速く強くなって最後に「ドーン!!」）、レアスキルの Lv3 なら「超激熱!!!」で虹色になる。

## キャラ選択（通常モード）

「スタート」でキャラを選んでから始める。チートモードはパスタマン固定。画像は `game/chara/*.webp`。

| キャラ | メリット | デメリット |
|---|---|---|
| パスタマン | すべてふつう | なし |
| 5号（Lua）HARD | 点数3倍 | 攻撃ブロックが1周目から多い・お皿が少し小さい |
| 2号（Bito） | お皿が30%広い | 動きが遅い・分身の時間が半分 |
| 4号（Coordi） | 点数1.5倍・コンボが切れにくい | お皿が20%狭い・ボールが速い |
| 3号（Nera） | 全部のブロックを1発で壊す（鉄の壁も） | 発射は何があっても1発・必殺技のボールが1/3 |
| 6号（Miya） | 動きがとても速い・ステージごとに1回ボールを救出 | お皿が25%狭い |
| マスター（Mako） | アイテム2倍・落ちてくるアイテムを拾いやすい | 必殺技ゲージが半分 |
| 1号（ぱすたまん。） | ステージごとにランダムで能力（お皿ワイド・貫通・ずっと分身・アイテム2倍・点数2倍・ゲージ急速） | 点数0.7倍（「点数2倍」の能力のときは1.4倍）・ステージごとにランダムで弱点（お皿が小さい・ボールが速い・しびれやすい・動きが遅い・アイテム半分） |

ランキングは全キャラまとめて1つで、名前の横に使ったキャラが出る（`gas/ranking.gs` を新バージョンでデプロイすると有効）。

## チートモード（フォームチェンジ）

タイトルの「チートモード」からフォームを選ぶと、全部のボールがそのフォームのアイテム効果をずっと持つ。スコアはランキングに送らない。

| フォーム | アイテム | ボールの効果 |
|---|---|---|
| カルボナーラ | チーズ | 壊したブロックのまわり（最大9個）もとろけて消える |
| ミートソース | 肉 | 全部のボールが肉団子。何かに当たるたびに小さい肉団子が4方向へ飛び、小さい肉団子はブロックに当たると十字の5マス（硬いものも）をまとめて消して消える |
| アラビアータ | 唐辛子 | 全部のボールがずっと貫通球 |
| きのこ | きのこ | 壁・ブロック・お皿で跳ね返るたびに、いちばん近いブロックへまっすぐ飛ぶ |
| ペスカトーレ | ムール貝 | 当たるたびに小さく爆発（石は壊さない） |
| イカスミ | イカ | 当てると半径2マスに墨が広がり、ときどき8方向に墨が飛ぶ。墨の上はボールがすり抜けながら壊す |
| たらこ | 明太子 | 分身パスタマン（半透明）がずっといる |
| ペペロンチーノ | にんにく | にんにくガードがずっと出ている |

アイテム「イカ」は8方向に墨を飛ばし、墨がついたブロック（鉄の壁以外）は1発で壊れる。「なすび」は「にんにく」に変わった（効果は同じ）。
